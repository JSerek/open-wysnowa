# v1 Archive — full L0–L4 pipeline docs

These documents describe the **v1** EQD-AI pipeline (L0 preprocessing → L1
extraction → L2 theme synthesis → L3 18-metric suite → L4 analyst brief). They
are kept here as history/knowledge after the v2 pivot to an evidence-extraction
(L0–L1) focus.

For the active v2 direction see `docs/v2/` (`V2_FOUNDATION.md`, `V2_ROADMAP.md`)
and the project `CLAUDE.md`. The full v1 codebase is also preserved in the
`v1-full-pipeline` git tag / `archive/full-pipeline` branch.

Contents:
- `ARCHITECTURE.md` — full L0–L4 architecture
- `design/` — LAYER4 (analyst) and LAYER5 (future lenses) design
- `planning/` — v1 sprint plan + testing plans (PLAN, EQD_AI_Testing_Plan,
  STABILIZATION_TESTING_PLAN)
- `testing/` — v1 stabilization run summaries (L1 learnings already harvested
  into `docs/v2/V2_FOUNDATION.md`) + canonical_top10 test plan
- `reference/` — v1 architecture (v0.1) and the 18-metric reference (.docx)
- `claude_change_idea.md` — v1-era enhancement notes (omitted-text idea now
  lives in `docs/v2/V2_ROADMAP.md`)

> Foundational docs that still apply to v2 were **kept active**, not archived:
> `docs/reference/DESIGN_PRINCIPLES.md`, the general LLM/agent guides, the initial
> concept, and `docs/design/CODEBOOK_VERSIONING_DESIGN.md` (the codebook is core
> to L1).
